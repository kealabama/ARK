Réglages

Ton portefeuille reste sur cet appareil.

Sauvegardes

Garde une copie dans tes fichiers avant de changer d’appareil ou de navigateur. Un export préparé n’est pas une confirmation que le fichier a été conservé.

Signature ARK

Effet bref au franchissement d’un nouveau palier, jusqu’à deux positions à la fois. Le réglage système « Réduire les animations » est toujours respecté.

Les multiples sont mesurés en USD, sur le coût des positions restantes. +100 % = ×2.

Confidentialité

Le code protège l’interface, sans chiffrer le stockage ni les exports. Le mode œil masque les vues ; les formulaires de modification révèlent les valeurs nécessaires à la saisie.

Intégrité et reprise

Méthode : coût moyen pondéré global par actif, frais d’achat inclus. Un transfert conserve le coût. USD, USDT et USDC sont valorisés à parité. Le gain est exprimé en USD ; l’affichage BTC convertit la valeur actuelle.

Utilisation locale

L’interface fonctionne sans dépendances externes. Internet est nécessaire pour actualiser les cours. Sur GitHub Pages, garde la même adresse et le même navigateur pour retrouver tes données. Le fichier HTML ne contient pas tes opérations ; elles restent dans le stockage de cet appareil.

L’ouverture directe d’un fichier local peut utiliser un stockage différent selon le navigateur. Une page hébergée ne garantit pas sa réouverture sans réseau. Exporte toujours avant un changement d’adresse.
